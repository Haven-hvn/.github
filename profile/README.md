We build open-source tools where AI agents own themselves, data stays encrypted, and platforms don't hold the keys. From haven-cli our decentralized video archival tool using TACo and Filecoin to vlm-engine AI-powered media analysis without the corporate overhead—our stack ensures user sovereignty. No backends, no gatekeepers, no data silos.
