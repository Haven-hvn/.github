We are a research team building open-source tools with a strong focus on AI, data privacy, and decentralized processing. Our work centers on developing applications that integrate AI, encryption protocols, decentralized file storage, and analytics, ensuring secure, user-owned data processing.

Our flagship project is Haven Player, a modern video analysis application. It combines AI-powered analytics with a decentralized tech stack, including Filecoin for on-chain cloud storage and the Lit Protocol for encryption, giving users full control over their data and content.
